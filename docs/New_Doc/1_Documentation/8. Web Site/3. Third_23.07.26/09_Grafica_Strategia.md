# Fase 3 — strategia grafica

## Obiettivo

Passare da una UI DeFi ben eseguita a un'identità Jethos proprietaria. Il segno visuale centrale sarà il **capital path**: una linea che cambia stato attraversando wallet, autorizzazione, vault e protocolli.

## Sistema

- mint = capitale disponibile e sotto controllo del wallet;
- violet = capitale programmato nel vault;
- cyan = prova e osservabilità;
- amber = limiti, PoC e attenzione;
- numerazione editoriale per i principi;
- superfici meno uniformi e composizioni asimmetriche;
- ledger lines e receipt per rendere concreta la trasparenza.

Non aggiungere asset pesanti: identità tramite CSS, SVG e layout.
