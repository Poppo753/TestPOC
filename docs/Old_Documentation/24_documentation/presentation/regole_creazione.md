L’idea è: un documento sorgente (Word o OneNote) con sezioni coerenti, e ogni slide descritta con un formato ripetibile.

Struttura del file sorgente (Word consigliato)
Impostazioni (importanti)

Usa Stili:

Titolo documento = Titolo 1

Sezioni = Titolo 2

Ogni slide = Titolo 3

Bullet = elenco puntato normale

Evita frasi lunghe: meglio bullet brevi e densi.

Metti una slide = un blocco (niente due slide mischiate nello stesso paragrafo).

Template “Slide Spec” (copiaincolla)
Front matter (brief del deck)

Metti questo all’inizio del documento:

DECK TITLE: <Titolo presentazione>
AUDIENCE: <es. management / clienti / team tecnico>
GOAL: <cosa deve ottenere questa presentazione>
TONE: <professionale / consulting / tecnico / sales>
DURATION: <es. 10 min / 20 min>
STYLE RULES:

Font: <se hai preferenze>

Palette: <se c’è brand>

Evita: <es. emoji, meme, troppi colori>

Usa: <icone semplici, grafici puliti>

GLOBAL INSTRUCTIONS PER COPILOT:

Mantieni stile coerente e minimal

Usa titoli brevi e forti

Non superare 5 bullet per slide (se servono dettagli, mettili in note)

Preferisci grafici/diagrammi quando c’è numeri o processi

Ogni slide deve avere un “takeaway” chiaro

Template per OGNI slide (versione completa)
SLIDE 01 — <Titolo slide>

TYPE: <scegli uno: Title / Agenda / Section Divider / Bullet / Two-Column / Comparison / Timeline / Process / Diagram / Chart / Table / Quote / Image>
PURPOSE: <perché esiste questa slide, 1 riga>
ONE-LINER TAKEAWAY: <messaggio che deve rimanere>

ON-SLIDE CONTENT:

Headline: <titolo corto e incisivo>

Subheadline (optional): <1 riga>

Bullets (max 3–5):

…

…

…

VISUAL (specifica cosa vuoi):

<es. “Process diagram a 4 step”, “timeline 2021–2026”, “bar chart con 3 categorie”, “icona per ogni bullet”, “immagine di sfondo neutra”>

Data (se serve):

<numeri esatti, unità, fonte se c’è>

LAYOUT RULES (facoltativo ma utile):

Allineamento: sinistra/centrato

Enfasi: evidenzia <parola/numero>

Spazio bianco: alto

Densità: bassa/media/alta

SPEAKER NOTES (copilot le usa benissimo):

Cosa dico a voce (30–60 sec): …

Esempio/aneddoto: …

Transizione alla prossima slide: …

DO / DON’T:

DO: <es. “usa icone minimal”>

DON’T: <es. “non usare immagini stock con persone”>

Varianti “pronte” per i casi più comuni (copy/paste)
1) Slide “Agenda”

TYPE: Agenda
ON-SLIDE CONTENT:

Headline: Agenda

Bullets (4–6 max):

…

…

…

…
VISUAL: numerazione pulita + icone leggere
NOTES: “Oggi faremo… e alla fine decidiamo…”

2) Slide “Section Divider”

TYPE: Section Divider
ON-SLIDE CONTENT:

Headline: <Nome sezione>

Subheadline: <perché questa sezione conta>
VISUAL: background semplice + 1 icona grande
NOTES: 15 secondi, serve solo ritmo

3) Slide “Two-column”

TYPE: Two-Column
ON-SLIDE CONTENT:

Left title: <concetto A>

bullet…

Right title: <concetto B>

bullet…
VISUAL: divider centrale, simmetria
NOTES: confronto diretto

4) Slide “Comparison”

TYPE: Comparison
ON-SLIDE CONTENT:

Tabella 2–3 colonne, 4–6 righe

Evidenzia “winner” o “recommended”
VISUAL: check/cross o highlight
NOTES: concludi con una raccomandazione netta

5) Slide “Process”

TYPE: Process
ON-SLIDE CONTENT:

Headline: <processo>

Step 1–5 con verbi (es. “Raccogli”, “Valida”, “Esegui”, “Monitora”, “Itera”)
VISUAL: flow orizzontale con frecce
NOTES: 1 frase per step

6) Slide “Timeline”

TYPE: Timeline
ON-SLIDE CONTENT:

Anni o fasi con milestone
VISUAL: linea temporale pulita
DATA: date precise
NOTES: enfatizza “oggi siamo qui → prossimo step”

7) Slide “Chart”

TYPE: Chart
ON-SLIDE CONTENT:

Headline: <insight in una frase>

Callout number: <numero chiave>
DATA:

Serie: …

Unità: …

Fonte: …
NOTES: “questo grafico dimostra che…”

Regole d’oro (queste aumentano tantissimo la qualità)

Titoli = conclusioni, non descrizioni

NO: “Risultati Q4”

SÌ: “Q4 supera target: +18% YoY”

Ogni slide deve rispondere a una domanda (scrivila in PURPOSE)

Numeri sempre con unità e periodo (“+12% YoY”, “€ 3.2M 2025”)

Bullet corti, note lunghe (Copilot può mettere il testo lungo nelle note)

Se una slide ha troppi dettagli: split in 2 (Copilot tende a comprimere male)
