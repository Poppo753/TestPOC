## SLIDE 1.1 - I tuoi soldi perdono valore ogni giorno

### 📌 Layout
- **Sfondo**: Gradiente scuro (blu navy → nero)
- **Titolo**: Grande, centrato, bianco
- **Grafico**: Occupa 60% della slide, a destra
- **Testo**: Bullet points a sinistra

### 📝 Contenuto Testuale

**TITOLO**: 
```
I tuoi soldi perdono valore ogni giorno
```

**SOTTOTITOLO** (opzionale):
```
Il problema che nessuno ti dice
```

**BULLET POINTS** (a sinistra del grafico):
```
• Rendimento conto corrente: 0.1% annuo
• Inflazione media: 3-5% annuo
• Perdita reale: -3% all'anno
• In 10 anni: -26% del potere d'acquisto
```

**FRASE D'IMPATTO** (in basso):
```
"€10,000 oggi valgono €7,400 tra 10 anni. Senza fare nulla."
```

### 📊 Grafico Richiesto

**Tipo**: Grafico a linee (Line Chart)

**Dati da visualizzare**:
| Anno | Valore Nominale (€) | Valore Reale (€) |
|------|---------------------|------------------|
| 0 | 10,000 | 10,000 |
| 1 | 10,010 | 9,700 |
| 2 | 10,020 | 9,409 |
| 3 | 10,030 | 9,127 |
| 5 | 10,050 | 8,587 |
| 10 | 10,100 | 7,374 |

**Linea 1**: "Valore Nominale" - Colore grigio, quasi piatta
**Linea 2**: "Valore Reale" - Colore rosso, in discesa

**Etichette asse X**: Anno 0, 2, 5, 10
**Etichette asse Y**: €7,000 - €10,000

**Annotazione sul grafico**: Freccia che indica il gap tra le due linee con testo "-26%"

### 🎨 Note Design
- Font titolo: Bold, 48pt
- Font bullet: Regular, 24pt
- Colore accento: Rosso per enfatizzare la perdita
- Animazione suggerita: Linea rossa si disegna progressivamente

## SLIDE 1.2 - Le alternative esistono, ma sono complicate

### 📌 Layout
- **Sfondo**: Stesso gradiente scuro
- **Titolo**: In alto a sinistra
- **Immagine/Screenshot**: Centro-destra (60% slide)
- **Lista icone**: A sinistra

### 📝 Contenuto Testuale

**TITOLO**:
```
Le alternative esistono, ma sono complicate
```

**SOTTOTITOLO**:
```
La DeFi offre rendimenti, ma...
```

**LISTA CON ICONE** (ogni item con icona):
```
🔐 Wallet: seed phrase, chiavi private, sicurezza
⛽ Gas: ETH per ogni transazione, prezzi volatili  
🌉 Bridge: trasferire tra chain, rischi di hack
📉 Slippage: perdite nascoste negli swap
💀 Liquidation: rischio di perdere tutto
📚 Learning curve: mesi per capire come funziona
```

**FRASE D'IMPATTO** (in basso):
```
"Per guadagnare il 5% devi diventare un esperto crypto"
```

### 🖼️ Immagine/Visual Richiesto

**Opzione A - Screenshot**:
Screenshot di una UI DeFi complessa (es. Uniswap con impostazioni avanzate, o dashboard Aave con health factors)
- Deve apparire intimidatoria
- Molti numeri, grafici, bottoni

**Opzione B - Illustrazione**:
Persona confusa davanti a uno schermo con:
- Fumetti con termini crypto: "APY", "TVL", "Impermanent Loss", "Gas Fee", "Slippage"
- Espressione frustrata

**Opzione C - Icone Grid**:
Griglia 3x2 con icone grandi:
| Wallet 🔐 | Gas ⛽ | Bridge 🌉 |
| Slippage 📉 | Liquidation 💀 | Learning 📚 |

Ogni icona con X rossa sopra o colore rosso/arancione

### 🎨 Note Design
- Contrasto tra semplicità del messaggio e complessità dell'immagine
- Colori freddi/intimidatori per l'immagine
- Lista icone animate una alla volta (opzionale)

## SLIDE 1.3 - Serve un ponte

### 📌 Layout
- **Sfondo**: Stesso gradiente, ma con elemento centrale
- **Titolo**: In alto, centrato
- **Diagramma**: Centro slide (70%)
- **Testo minimal**: Solo etichette

### 📝 Contenuto Testuale

**TITOLO**:
```
Serve un ponte
```

**SOTTOTITOLO** (opzionale):
```
Tra la semplicità e i rendimenti
```

**ETICHETTE DIAGRAMMA**:
- Lato sinistro: "BANCA" | "Semplice" | "0% rendimento"
- Lato destro: "DEFI" | "Complicata" | "5-15% rendimento"
- Centro (ponte): "NOI"

**FRASE D'IMPATTO** (in basso):
```
"Semplicità bancaria + Rendimenti DeFi = La nostra soluzione"
```

### 📊 Diagramma Richiesto

**Tipo**: Illustrazione ponte/gap

**Struttura visiva**:
```
    🏦 BANCA                              📊 DEFI
    ┌─────────┐                          ┌─────────┐
    │ SEMPLICE│                          │COMPLESSA│
    │  0.1%   │                          │  5-15%  │
    │         │                          │         │
    └────┬────┘                          └────┬────┘
         │                                    │
         │           ┌─────────┐              │
         │           │   NOI   │              │
         └───────────┤  PONTE  ├──────────────┘
                     │ 🌉      │
                     └─────────┘
```

**Elementi grafici**:
- Lato BANCA: Icona banca classica, colore grigio/blu spento
- Lato DEFI: Icone crypto/grafici, colore verde/viola
- PONTE: Colore primario del brand (es. blu elettrico/verde)
- Frecce che mostrano il flusso da entrambi i lati verso il centro

**Animazione suggerita**: 
1. Appaiono i due lati (gap evidente)
2. Appare il ponte che li collega
3. Highlight sul ponte con glow

### 🎨 Note Design
- Questo è il momento "aha!" - il visual deve essere chiaro e memorabile
- Il ponte deve essere prominente e con colore brand
- Minimal text, massimo impatto visivo
