## Completeness notes

- Hardware/device runtime: none. Hardware-wallet mentions are operational documentation only; `navigator.hardwareConcurrency` is a WebGL performance hint.
- Product providers: Coinbase CDP, Sumsub, Monerium, Reap, and 21X are absent from runtime code and therefore are external/target dependencies, not current components.
- Safe SDK usage belongs to administrative automation. It is not evidence of a user-owned CDP Smart Account.
- Generated files do not override source, but deployment-matched bytecode is evidence when source and live code diverge.
