# Legacy material

Nothing in this directory is used by the active website entry points.

| Directory | Contents |
|---|---|
| `prototype/` | Previous component system and its old entry module |
| `reference/` | Historical API references, dependency graph and documents |
| `data/` | Superseded plugin and roadmap JSON |
| `media/` | Unreferenced experimental background media |

The material is retained for comparison and recovery. Do not import it into the
active site without first moving the required source into the appropriate
`assets`, `data` or `content` domain and adding validation.
