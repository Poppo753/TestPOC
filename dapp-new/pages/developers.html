Developers

Build against explicit deployment records.

The current web console targets the private Arbitrum USDC PoC and keeps deployment config, ABI, readers, estimates and transactions in separate modules.

Run locally

From dapp-new:

python -m http.server 8000

Then open http://localhost:8000/

User entry points

  • USDC approve to LiquidityManager.
  • LiquidityManager.deposit(uint256).
  • LiquidityManager.withdrawWithDeadline(uint256,uint256).
  • Events for deposit and withdrawal history.

Normal users do not call plugins directly.

Frontend module boundaries

Config & ABI

Immutable PoC description and minimal callable interfaces.

Readers & estimates

Read-only snapshots and explicitly indicative client-side calculations.

Transactions

Validated approval, deposit, withdrawal and revoke workflows.

Do not copy addresses between deployments. A base-asset deployment is a distinct vault system. Update config from a verified manifest and test every ABI against deployed bytecode.
